# Data Structures and Algorithms in C - Lab Reports

This repository contains implementations of various data structures and algorithms in C, alongside corresponding lab reports. These lab reports provide detailed explanations, theoretical concepts, and step-by-step instructions for understanding the implementations of key algorithms and data structures.

## Features:
- **C Code Implementations**: Clean, well-commented code for data structures like arrays, linked lists, stacks, queues, trees, heaps, and graphs, and algorithms like sorting, searching, and dynamic programming.
- **Lab Reports**: Detailed reports covering theoretical concepts, working principles, time and space complexities, and sample input/output for each implementation. These reports serve as documentation to support the code and provide deeper insights into the practical applications of each topic.
- **Code Examples**: Example programs are included to demonstrate the usage of each data structure and algorithm in various contexts.

## Structure:
- Each lab report corresponds to a specific data structure or algorithm and includes:
  - Theory and explanation.
  - Code implementation in C.
  - Sample input/output.
  - Complexity analysis.
- Code files and reports are organized to ensure ease of understanding and access.
