# Data Structures and Algorithms in C - Lab Reports

This repository contains implementations of various data structures and algorithms in C, organized as lab reports. Each lab report includes the corresponding C code for a specific data structure or algorithm, aimed at helping you understand and practice key concepts in computer science.

## Features:
- **C Code Implementations**: Clean, well-commented code for data structures like arrays, linked lists, stacks, queues, trees, heaps, and graphs, as well as algorithms like sorting, searching, and dynamic programming.
- **Lab Reports**: Each lab report contains the implementation of a specific data structure or algorithm. The reports include:
  - The code implementation in C.
  - Sample input/output to demonstrate the working of the code.
- **Code Examples**: Example programs to show the usage of each data structure and algorithm in various contexts.

## Structure:
- Each lab report corresponds to a specific data structure or algorithm and includes:
  - The C code implementation.
  - Sample input/output for the code.
- Code files are organized to ensure ease of understanding and access.
